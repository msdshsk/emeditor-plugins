# memo_tidy

話を聞きながら取った走り書きのメモを `claude -p` で整理し、選択範囲を置き換える。
トピックごとに MECE に分類し、Markdown の見出しと箇条書きにする。決定事項・TODO・未決事項には【決定】【TODO】【未決】の印が付く。

## 前提

- Claude Code（`claude.exe`）がインストール済みで、ログイン済みであること
- `claude.exe` は PATH から探し、見つからなければ `%USERPROFILE%\.local\bin\claude.exe` を使う

## 使い方

- 整理したい範囲を選択して、プラグイン メニュー > Claude でメモ整理（選択が無ければ文書全体）
- 実行中はメニュー/ボタンがチェック状態になる。もう一度実行するとキャンセル
- 結果で選択範囲が置き換わる。気に入らなければ Ctrl+Z で戻せる
- 待っている間に文書を編集した・タブを切り替えた場合は、置き換えずにアウトプット バーに出す

## 設定

「プラグインの設定」で Claude でメモ整理 を選び「プロパティ」:

- **原文を残す**: オンにすると、次の形で置き換える

  ```
  {原文}
  ↓↓↓
  {整理結果}
  ```

## 例

入力:

```
田中さん 来月リリース 厳しい？
テスト環境 まだ用意できてない→佐藤さん 金曜まで
デザイン修正 3画面
リリース日 6/15 で一旦決定
予算 追加いるかも 部長に確認
テスト環境は佐藤さん
ログイン画面のデザインどうする？要検討
```

出力（約 12 秒）:

```markdown
## リリース日程
- 田中さん：来月リリースは厳しい？
- 【決定】リリース日は 6/15 で一旦決定

## テスト環境
- まだ用意できていない
- 【TODO】テスト環境の準備（担当：佐藤さん、期限：金曜まで）

## デザイン修正
- 修正対象は 3 画面
- 【未決】ログイン画面のデザインをどうするか（要検討）

## 予算
- 追加が必要になるかもしれない
- 【TODO】予算追加の要否を部長に確認
```

## 仕組み

```
claude.exe -p --tools "" --strict-mcp-config --no-session-persistence --system-prompt "<整理の方針>" "次のメモを整理してください。"
  stdin  ← 対象テキスト（UTF-8）
  stdout → 整理結果
```

- `--tools ""`: ツールを全部無効化（ファイル読み書きやコマンド実行をさせない）
- `--strict-mcp-config`: ユーザー設定の MCP サーバーを読み込まない（コスト約 1/3、応答も速くなる）
- `--no-session-persistence`: セッション履歴を残さない
- 作業フォルダは `%TEMP%\emeditor-memo-tidy`（空）。カレントの CLAUDE.md などを読ませないため
- 実行はワーカースレッド。プロセス管理は [shared/process_runner.h](../../shared/process_runner.h)
